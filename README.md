# QQ-Alerta

Página embutida no script do Genesys Cloud (componente Web Page) que toca um bipe e pisca em vermelho
quando o cliente desliga e a tabulação ainda está pendente.

URL usada no script:

```
https://lucass4me.github.io/QQ-Alerta/alerta.html?conversationId={{scripter.interactionId}}
```

Teste de som (sem login): `https://lucass4me.github.io/QQ-Alerta/alerta.html?teste=1`
